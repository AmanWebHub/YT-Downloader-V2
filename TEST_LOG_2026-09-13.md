| Previous custom location is not retained as the next session's default | PASS   |

### Location Behavior

The Browse/location behavior was intentionally changed so that a custom location selected by the user is **session-only**.

If the user selects another folder, YTDownloader uses that location for the current session. When YTDownloader is closed and started again, the application returns to the default download location.

This prevents an old custom location from unexpectedly becoming the default for future sessions.
